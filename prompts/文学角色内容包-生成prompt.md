## 1. 维度定义（10 个核心维，无隐藏维）

这是本内容包的核心：用一套**人格维度**描述角色（而非文学口味里"写作风格"的维度）。
10 个维度、key 固定如下，label 和 adj 照抄：

| key | label | adj | 高分意味着 | 低分意味着 |
|---|---|---|---|---|
| action | 行动 | 目标驱动 | 主动、进取、说做就做 | 被动、随缘、等事找上门 |
| emotion | 情感 | 情感丰沛 | 感性、情绪外露、易被打动 | 理性、克制、冷眼旁观 |
| inner | 内省 | 心思复杂 | 多思、敏感、反复掂量 | 简单直白、不内耗 |
| dream | 想象 | 理想奔放 | 理想主义、天马行空 | 务实、脚踏实地 |
| care | 关怀 | 心怀他人 | 把他人与世道放心上 | 独善其身、守好自己 |
| thought | 思辨 | 追问意义 | 爱问"为什么"、追问意义 | 活在当下、不钻牛角尖 |
| order | 守序 | 规矩自持 | 重秩序、守规矩、求完美 | 随性自由、不拘一格 |
| wit | 幽默 | 反讽机智 | 幽默、会心、看破不说破 | 严肃、一本正经 |
| desire | 欲望 | 野心渴求 | 欲望强烈、想要就要 | 淡泊自足、无求 |
| tough | 坚韧 | 扛得住事 | 坚韧、越挫越勇、能扛事 | 敏感、易碎、易被击垮 |

dims 数组照抄：

## 2. 题目规格（类型 × 数量 × 写法）

**共 48 题，6 种题型**（题型名 `format` 沿用，保证后端分层抽样 + 维度覆盖保证照常工作）：

| format | 含义 | 数量 |
|---|---|---|
| reality | 现实生活情境 | 8 |
| fantasy | 奇幻 / 假设情境 | 10 |
| social | 社交 / 关系 / 群体 | 7 |
| inner | 内心 / 独处 / 回忆 | 10 |
| commitment | 投入 / 取舍 / 扛事 | 6 |
| desire | 欲望 / 野心 / 诱惑 | 7 |

**每题结构**（对齐 `questions.js` 现有字段）：

```js
{ id: 1, format: 'reality', context: null, prompt: '……', options: [
  { id: 'A', text: '……', vector: { action: 3, care: 1 } },
  { id: 'B', text: '……', vector: { emotion: 2, care: 1 } },
  { id: 'C', text: '……', vector: { inner: 2, thought: 2 } },
  { id: 'D', text: '算了，不深究。', vector: {}, avoid: true },
] }
```

**写法铁律（务必遵守）：**

1. 每题 4–5 个选项，单选。情境脱离读书、贴合真实生活或轻度奇幻，让谁都能答。
2. 每个选项的 `vector` **只给 1–2 个维度，系数 +2 或 +3，全部非负**。不要撒胡椒面，不要负系数——"不喜欢某倾向"通过"给对立维度加分"来表达，而不是给该维减分（否则归一化公式会被负系数搅乱）。
3. 表示"回避 / 翻篇 / 不深究 / 算了 / 与我无关"的选项，`vector` 留空并标 `avoid: true`。每 5 题里至少 1 题要有这种选项（引擎靠它做"无偏好检测"）。
4. 少数题可带 `followUp`（追问层），结构为 `followUp: { prompt, options: [{id,text,vector}] }`，规则同上。全库 3–5 道即可，不要多。
5. 每道题要干净地测 2–3 个维：不同选项分别指向不同倾向，而不是五个选项测同一个维。

**示例（作为模板，可复用改写）：**


## 4. 结算方式（计分 + 匹配公式）

**config 照抄：**

```js
config: {
  mode: 'profile',             // 雷达匹配型（非分类型）
  weights: { style: 1.0, difficulty: 0 },  // 纯风格契合，无难度分量
  coreScale: 5,                // 核心维归一化缩放
  hiddenScale: 1.25,           // 无隐藏维，保留字段但不起作用
  avoidThreshold: 0.5,
  enhanceK: 1.8,
  flatThreshold: 2.5,
  allRounderHigh: 7.5, allRounderMinCount: 6, allRounderFloor: 4,
  peakMin: 8.5, maxGap: 1.5,
  difficulty: null,            // 角色没有"阅读难度"，关闭难度分量
  extractBooks: true,          // 从角色出处（works）抽《书名》生成"推荐原著"
}
```

**结算公式（引擎已实现，此处说明语义，生成内容时按此校准）：**

设用户选了 n 题（每题单选，有追问则两层各算一次），维度集合 `D`（10 个）。

1. **原始累计**：`raw[d] = Σ 被选选项的 vector[d]`（d ∈ D）
2. **满分基准**：`avail[d] = Σ 这 n 题里所有选项的 vector[d]`（该维可被吃到的信号总量）
3. **归一化**（吃到的信号比例 → 5~10）：
   `core[d] = clamp( 5 + (raw[d] / avail[d]) × 5 , 0, 10 )`，若 `avail[d]=0` 则 `core[d]=5`（中性）
4. **无偏好收缩**：`avoidRatio = 选中的回避选项数 / 出现回避选项的题数`；若 `avoidRatio ≥ 0.5`，令 `k = (avoidRatio−0.5)/0.5`，`core[d] = 5 + (core[d]−5)×(1−k)`（向 5 收缩）
5. **对比增强**（只用于匹配，不改雷达图）：`mean = Σ core[d]/10`；`enhance[d] = clamp( 5 + (core[d]−mean)×1.8 , 0, 10 )`
6. **契合度**（中心化余弦）：对每个角色 e：
   `S10(e) = ( cosine(enhance, e) + 1 ) / 2 × 10`，其中
   `cosine(u,e) = Σ_d (u[d]−5)(e[d]−5) / ( √Σ(u[d]−5)² · √Σ(e[d]−5)² )`
7. **最终分**：`final(e) = 1.0 × S10(e)`（无难度项）
8. **排序输出**：final 降序 → **top = 第 1 名**（最契合角色）、**family = 前 3**、**also = 第 2–6 名**；并列时按 entities 数组顺序稳定排序。

**给角色打分时的一条标尺**（保证 72 个角色打分一致）：
- 8–10：该角色的标志性特质（一说名字就想到的）
- 5–7：有但不突出
- 2–4：明显相反或很弱
- 0–1：完全相反
- 每个角色的"主维度"给 8–10，"低维度"给 2–4，其余 5–7；避免全部角色都堆在 7–9（区分度会消失）。

## 5. 文案（copy）要求

```js
copy: {
  soul: { /* 10 个维 × high/low 各一句，见下 */ },
  readingTips: { /* 10 个维各一句，讲"这个角色的底色" */ },
  challenge: {},          // 无难度，留空
  profileLines: {},       // 无隐藏维、无 patience，留空
}
```

- **soul**：面对"你"的第二人称、文学化、有质感，每句 30–50 字，不照抄外部文案。结构对齐 `tests/literary-taste/test.js` 里的 `copy.soul`（每个 key 下 `{ high, low }`）。示例（action 维）：
  - high：`你骨子里有一股劲，认定了就往前冲，不习惯站在原地等。`
  - low：`你更愿意顺其自然，让事情自己走到你面前。`
- **readingTips**（结果页里"角色的底色"）：10 维各一句，讲**这个角色**的底色，而非教用户怎么读。示例（desire 维）：`这个角色最迷人的，是他那股不肯放手的劲。`
- **pronouns**：`female` 列出上面所有 ♀ 角色名；`defaultSubj: '他'`。
