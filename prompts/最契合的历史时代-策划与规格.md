# 最契合的历史时代 · 策划案 + 内容包规格

> 定位：并列项目第四个内容包。核心钩子——
> **「如果你生活在另一个时代，你最可能属于哪里？」**
> 不是"你最想穿越去哪个时代"（那是向往），而是"你的性格气质，最像哪个时代的空气"。结果是具体时代 + 一段文学化的、适合截图的漂亮文案 + 一张复古时代明信片。

---

## 0. 一句话结论

复用平台引擎（纯余弦匹配，同动物/音乐），只写 `tests/era/` 内容包。核心差异在两点：

1. **维度**：全新"时代气质 10 维"——测的是"你以什么精神气质活着"，既能从当下的生活偏好测出，又能标到历史时代上。
2. **视觉**：时代主题是四个内容包里**最适合做极致视觉**的——每个时代配专属配色 + 意象 emoji + 分享卡做成"复古时代明信片"（羊皮纸纹理 / 版画感 / 时代印章）。这是它传播的命门。

---

## 1. 核心钩子与差异化

| | 普通"历史测试" | 本项目 |
|---|---|---|
| 问法 | 你想穿越到哪个朝代？(选唐朝) | 深夜独处、你更想让时间怎样流过？(间接测气质) |
| 结果 | "你适合生活在唐朝" + 一段介绍 | "你属于盛唐长安。" + 时代文学解读 + 一张复古明信片 |
| 气质 | 趣味占卜 | 时代精神的归属感，认真、有解释力、极度可截图 |

**关键区分（务必守住）**：题目绝不同"你想去哪个时代 / 你喜欢哪个朝代的什么"，只问**当下的你如何感受世界**——你的信仰、你的节奏、你对秩序和野蛮的态度、你是向上还是黄昏。时代是结果，不是提问素材。

**定位声明（重要）**：本测试描述的是**历史想象中的时代精神**，是文化意象与气质切片，不是历史教科书。允许浪漫化的表达（如"西部神话"、"自由是用命换来的"），但**条目名称必须是具体的时代/政权/年代**（如"古典雅典"而非"古希腊"、可以保留"中世纪欧洲（哥特时代）"作为聚焦），避免"文明 + 城市 + 运动 + 年代 + 贸易路线"混在同一级造成颗粒度不一。

**文案模板**（每个时代固定结构）：

```
[意象 emoji + 你属于X。]
[3–4 句文学化解读：把你此刻的气质，翻译成那个时代的一缕风]
[一句"时代金句"（可独立成明信片落款）]
```

## 2. 维度（全新"时代气质"10 维）

每一维都是"一个时代的精神质地"，也是"你当下的活法"。高分 = 靠近该维"上端"。

| key | label | 高分（↗ 你是这样） | 低分（↘ 你是这样） |
|---|---|---|---|
| faith | 信仰 | 相信超验、天命、神圣感 | 世俗理性、怀疑、现世 |
| rule | 礼序 | 重等级、礼仪、规则清晰 | 自由、混杂、不拘一格 |
| tribe | 群系 | 重集体、人情、荣誉纽带 | 个人、独立、疏离自足 |
| grace | 风雅 | 审美精致、讲仪式、生活美学 | 朴素、实用、粗粝直接 |
| mind | 学养 | 重思辨、学问、艺术哲思 | 重行动、经验、生存实干 |
| quest | 征途 | 开拓、冒险、向往远方 | 守成、安居、求稳 |
| edge | 边野 | 亲近蛮荒、未知、危险 | 依赖秩序、安全、文明 |
| tempo | 节律 | 快、喧闹、新变、瞬息 | 慢、静谧、传统、悠长 |
| gold | 荣光 | 黄金上升、笃信未来 | 黄昏颓靡、末世感 |
| fire | 烈度 | 情感炽烈、戏剧化、奔放 | 含蓄、克制、内敛 |

dims 数组照抄：

```js
dims: [
  { key: 'faith', label: '信仰', adj: '神圣超验' },
  { key: 'rule', label: '礼序', adj: '秩序尊崇' },
  { key: 'tribe', label: '群系', adj: '集体归属' },
  { key: 'grace', label: '风雅', adj: '生活美学' },
  { key: 'mind', label: '学养', adj: '思辨智趣' },
  { key: 'quest', label: '征途', adj: '开拓远方' },
  { key: 'edge', label: '边野', adj: '亲近蛮荒' },
  { key: 'tempo', label: '节律', adj: '快变喧闹' },
  { key: 'gold', label: '荣光', adj: '黄金上升' },
  { key: 'fire', label: '烈度', adj: '炽烈奔放' },
],
```

> 设计说明：这 10 维兼顾"双向可测"。`quest`（征途）与 `edge`（边野）容易混——前者测"想不想干大事/去远方"，后者测"受不受得了粗粝和危险"，靠"向往 vs 耐受"分开。`tempo`（节律）与 `gold`（荣光）也容易混——前者测快慢，后者测时代底色是向上还是向下，一个形容节奏、一个形容情绪。`grace`（风雅）与 `mind`（学养）一个是审美、一个是智识，分别承载"唐代的豪迈诗酒"与"宋代的思辨雅玩"。

## 3. 时代清单（60 个 · 9 板块 · 气质两两不撞）

每个条目：**意象 emoji + 时代名 — 时代精神一句话；主维；低维**。生成时按"打分标尺"转成 10 维向量。相邻板块共享部分维度，靠主维组合错开（详见 3.7 易混对）。

**向量生成规则（务必一致）**：`主维` 标签列出的维度，向量值必须 ≥8；`低维` 标签列出的维度，向量值必须 ≤4；其余维度 5–7。**主/低标签与 10 维数值必须完全对应**——标签写"低 faith / rule"，向量里 faith 和 rule 就绝不能 ≥5。

## 5. 结算方式（沿用平台引擎，零改动）

```js
config: {
  mode: 'profile',
  weights: { style: 1.0, difficulty: 0 },
  coreScale: 5, hiddenScale: 1.25, avoidThreshold: 0.5, enhanceK: 1.8,
  flatThreshold: 2.5, allRounderHigh: 7.5, allRounderMinCount: 6, allRounderFloor: 4,
  peakMin: 8.5, maxGap: 1.5, difficulty: null, extractBooks: false,
}
```

公式（同前）：

```
core[d]    = clamp( 5 + (raw[d]/avail[d]) × 5 , 0, 10 )
enhance[d] = clamp( 5 + (core[d] − mean) × 1.8 , 0, 10 )
final(e)   = ( 中心化余弦(enhance, 时代e) + 1 ) / 2 × 10
```

排序取第 1 名 =「你属于X」，前 3 =「与你相近的时代」，第 2–6 =「其次」。每个时代加一句 `why`（你与它同频的维度），供家族卡展示。

## 6. 结果页 & 分享设计（本项目的传播命门）

时代主题适合做**极致的复古视觉**，这是它和其他三个测试拉开的地方：

1. **Hero 区**：每个时代一个**专属配色 + 大号意象 emoji**（希腊🏛 / 唐🐉 / 宋📜 / 巴黎💐 / 上海🌆 / 纽约🗽…），配一句「你属于 X」的超大标题。背景可用该时代的"主色渐变"（如唐=金红、宋=青瓷、巴黎=紫铜、上海=墨绿+霓虹粉）。
2. **时代文学解读**：3–4 句第二人称——"你属于盛唐长安。你不信规矩，信的是酒、诗和天地……"。
3. **时代金句**：独立一行、引号、金色高亮，可作为明信片落款。
4. **相近的时代**：`family` 前 3，小卡带意象 emoji + 一句 why。
5. **雷达图折叠**：`foldRadar: true`，默认收起（视觉优先）。
6. **分享卡 = 复古时代明信片**（P0，重点做）：
   - canvas 竖版 720×1080，背景用该时代的**专属渐变 + 纸纹噪点**（模拟羊皮纸 / 老照片颗粒）。
   - 顶部大号意象 emoji + 时代名（衬线、描边），中部时代金句，底部一行"年代 · 地域"落款（如"618–907 · 长安"）。
