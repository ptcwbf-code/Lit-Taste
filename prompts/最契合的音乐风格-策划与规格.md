# 最契合的音乐风格 · 策划案 + 内容包规格

> 定位：并列项目第三个内容包。核心钩子（也是本项目区别于所有"音乐口味测试"的地方）——
> **「你是哪一种声音？」**
> 不是"你喜欢什么音乐"，而是"你像哪一种声音"。结果是具体风格 + 一段文学化的、适合截图的漂亮文案。

---

## 0. 一句话结论

音乐风格测试复用引擎与前端，只写 `entities.js`（64 种风格画像）+ `questions.js`（题目）+ `details.js`（文案）。但它需要一套**全新的"声音维度"**——这 10 个维度是"你以什么样的声音存在于世上"的人格隐喻，既能从生活情境里测出，又能标到每一种音乐风格上。

**出题哲学**：题目永远不问"你喜欢什么音乐 / 什么节奏 / 什么乐器"。但也不要写成普通的生活决策问卷——而是把每题做成一小段**声音氛围切片**：文字像歌词、像专辑封面、像一段电影氛围。让"做题"这件事本身，就接近"听到一首喜欢的歌"时的那种体验。你在氛围里的自然反应，被映射到声音维度。

**关于"同级"**：本版 64 种风格按 7 大类组织，每类内部的风格尽量处于同一层级（都是具体流派/分支，而非"大类和子类混排"），确保结果互相可区分、可解释。

---

## 1. 核心钩子与差异化

| | 普通"你爱听什么" | 本项目 |
|---|---|---|
| 问题 | 你更喜欢钢琴还是吉他？ | 深夜独处，你更想让时间怎样流过？ |
| 结果 | "你适合听爵士" + 歌单 | "你是 Ambient。你不需要音乐强调自己的存在……" |
| 气质 | 音乐推荐引擎 | 人格画像，认真、有解释力、可截图 |

**文案模板**（每种风格固定结构）：

```
[emoji + 你是X。]
[3–4 句文学化解读：第二人称、具体、不说教]
[一句"分享金句"（可独立成分享卡）]
```

## 2. 维度（全新"声音"10 维）

每一维都是"你作为一种声音 / 一种存在"的隐喻，高分 = 靠近该维的"上端"。

| key | label | 高分（↗ 你是这样的声音） | 低分（↘ 你是这样的声音） |
|---|---|---|---|
| warmth | 温度 | 温暖、热烈、有体温 | 冷冽、疏离、有距离 |
| intensity | 强度 | 迸发、燃烧、宣泄 | 克制、内敛、不惊动 |
| order | 秩序 | 严谨、结构、有条理 | 即兴、随性、打破框架 |
| groove | 律动 | 踩着节拍、摆动、流动 | 悬浮、无拍、漂浮不定 |
| nostalgia | 怀旧 | 回望、念旧、留有余温 | 前瞻、求新、面向未来 |
| texture | 质感 | 精致、光滑、被打磨 | 粗粝、手作、不修饰 |
| inward | 内省 | 向内、独白、自我 | 向外、表达、与世界共振 |
| melancholy | 忧郁 | 忧郁、悲悯、深色调 | 明快、轻盈、亮色调 |
| space | 留白 | 留白、呼吸、空间感 | 密实、填满、密度高 |
| aura | 气场 | 宏大、震撼、仪式感 | 贴身、亲近、日常感 |

dims 数组照抄：

```js
dims: [
  { key: 'warmth', label: '温度', adj: '有体温' },
  { key: 'intensity', label: '强度', adj: '迸发燃烧' },
  { key: 'order', label: '秩序', adj: '严谨结构' },
  { key: 'groove', label: '律动', adj: '踩着节拍' },
  { key: 'nostalgia', label: '怀旧', adj: '回望念旧' },
  { key: 'texture', label: '质感', adj: '精致打磨' },
  { key: 'inward', label: '内省', adj: '向内独白' },
  { key: 'melancholy', label: '忧郁', adj: '深色悲悯' },
  { key: 'space', label: '留白', adj: '留白呼吸' },
  { key: 'aura', label: '气场', adj: '宏大震撼' },
],
```

> 设计说明：这 10 维尽量正交。`秩序` 与 `质感` 是唯一偏"形式"的一对——前者测"讲不讲规矩/结构"，后者测"粗粝还是精致"。`怀旧` 与 `气场` 撑起了 City Pop / Synthwave / 古典跨界这批"氛围型"风格的区分。同级风格（如"爵士"族、摇滚族）靠主维组合拉开。

## 3. 风格清单（64 种 · 7 大类）

每个条目：**emoji 名 — 本质；介绍；主维；低维；向量；文案；金句**。
- `介绍` = 客观说明"这是怎样一种风格"，落进 `details.js` 让用户看得懂。
- `向量` 直接贴进 `entities.js`（10 维、0–10 整数）。已确保主维两两不撞脸。

### 一、摇滚与另类（15）

#### 🎧 独立摇滚 Indie Rock
- 本质：DIY、吉他、不肯从众的私语　·　主 texture/inward　·　低 aura
- 介绍：起源于独立音乐文化，强调个性化创作、吉他声音和相对非主流的审美，风格跨度很大。
- 向量：`{ warmth:6, intensity:6, order:4, groove:4, nostalgia:6, texture:4, inward:8, melancholy:7, space:6, aura:3 }`
- 文案：你是独立摇滚。你宁可粗糙，也不要精致得没有灵魂。你有自己的坚持，不喜欢被归类、被安排。你的表达是私密的、不迎合的——懂你的人不多，但懂的都是真的懂。
- 金句：宁可粗糙，也不要没有灵魂。

#### 🌗 另类摇滚 Alternative Rock
- 本质：主流边缘、多变、忧郁不归类　·　主 melancholy/texture　·　低 order
- 介绍：以区别于传统主流摇滚的声音和创作方式为特征，涵盖大量 90 年代以来的摇滚分支。
- 向量：`{ warmth:5, intensity:7, order:4, groove:6, nostalgia:6, texture:4, inward:7, melancholy:8, space:6, aura:5 }`
- 文案：你是另类摇滚。你不想被归进任何一个框里，主流和地下之间，你走自己的那条。你有点忧郁，也有点多变，今天这样、明天那样。你的不安分，恰恰是你最像自己的地方。
- 金句：不归类，才最像自己。

#### 🏔️ 后摇 Post-rock
- 本质：蓄势、爆发、无词的倾诉　·　主 intensity/space/melancholy　·　低 warmth/groove
- 介绍：通常弱化传统主歌副歌结构，以器乐、层层铺陈、动态变化和氛围营造为核心。
- 向量：`{ warmth:4, intensity:9, order:5, groove:3, nostalgia:4, texture:6, inward:7, melancholy:9, space:9, aura:8 }`
- 文案：你是后摇。你不急着说话，习惯把情绪一点点攒起来，直到它自己找到出口。你可以沉默很久，但爆发的那一刻，谁都无法忽视。你的温柔和你的力量，是同一种东西的两面。
- 金句：沉默攒久了，终会找到出口。

#### 🎇 盯鞋 Shoegaze
- 本质：模糊、沉浸、失焦的浪漫　·　主 space/inward/melancholy　·　低 groove/order
- 介绍：大量使用失真、混响和效果器制造厚重音墙，旋律通常隐藏在朦胧的声音层次中。
- 向量：`{ warmth:4, intensity:8, order:4, groove:3, nostalgia:5, texture:7, inward:8, melancholy:8, space:8, aura:6 }`
- 文案：你是盯鞋。你习惯低着头，沉浸在自己的世界里，对外界的目光有点躲闪。你的情感浓烈，却不宣之于口，只在自己心里嗡嗡作响。你的浪漫是失焦的、模糊的，越靠近越看不清。
- 金句：浓烈的情感，不宣之于口。

#### 🗡️ 后朋克 Post-punk
- 本质：冷峻、尖锐、跳舞的荒诞　·　主 melancholy/texture/groove　·　低 warmth
- 介绍：从朋克发展而来，但更加重视实验性、节奏、低音线和冷峻的声音设计。
- 向量：`{ warmth:3, intensity:7, order:6, groove:8, nostalgia:6, texture:5, inward:8, melancholy:9, space:6, aura:6 }`
- 文案：你是后朋克。你的冷静是尖锐的，像刀刃，不声张却很锋利。你一边冷眼旁观这个荒诞的世界，一边忍不住跟着它的节奏轻轻晃动。你的忧郁，是有棱角的。
- 金句：冷眼旁观，却忍不住晃动。

#### 🕯️ 哥特摇滚 Gothic Rock
- 本质：幽暗、戏剧、浪漫的深渊　·　主 melancholy/aura/inward　·　低 warmth
- 介绍：氛围阴郁、戏剧性强，常使用深沉的人声、贝斯和空间感明显的吉他。
- 向量：`{ warmth:3, intensity:7, order:6, groove:4, nostalgia:7, texture:6, inward:8, melancholy:10, space:6, aura:8 }`
- 文案：你是哥特摇滚。你不回避黑暗，反而在黑暗里找到了美。你喜欢深刻的东西，哪怕它带着一点悲情。你的浪漫是幽暗的、戏剧化的，像一支在夜里静静燃烧的蜡烛。
- 金句：在黑暗里，也能找到美。

#### 🌧️ 垃圾摇滚 Grunge
- 本质：90s、颓废、真实、失真　·　主 intensity/texture/melancholy　·　低 order/aura
- 介绍：90 年代西雅图场景的重要风格，融合朋克、硬摇滚等元素，声音粗粝而直接。
- 向量：`{ warmth:5, intensity:9, order:3, groove:5, nostalgia:7, texture:2, inward:6, melancholy:8, space:4, aura:4 }`
- 文案：你是垃圾摇滚。你讨厌精致和伪装，宁可真实得有点狼狈。你的情绪是粗粝的、下坠的，却有一种不肯假装的倔强。你的颓废不是放弃，是对这个世界的一种诚实。
- 金句：宁可狼狈，也不假装。

#### 🖤 情绪摇滚 Emo
- 本质：坦白、心碎、把心捧在手上　·　主 intensity/melancholy/inward　·　低 order/aura
- 介绍：强调私人情感和情绪表达，常以强烈的人声、动态变化和具有戏剧性的旋律为特点。
- 向量：`{ warmth:5, intensity:8, order:3, groove:5, nostalgia:6, texture:3, inward:9, melancholy:9, space:5, aura:4 }`
- 文案：你是情绪摇滚。你的情绪是敞开的，藏不住，也不想藏。你把心捧在手上，把最痛、最真的部分唱出来。别人说你太敏感，你只觉得——不这样，还叫活着吗。
- 金句：把心捧在手上。

#### 📐 数学摇滚 Math Rock
- 本质：复杂、跳拍、聪明的秩序　·　主 order/texture　·　低 nostalgia/warmth
- 介绍：使用复杂节拍、不规则结构、切分和精确的吉他演奏，具有明显的数学感和器乐性。
- 向量：`{ warmth:4, intensity:7, order:9, groove:6, nostalgia:3, texture:8, inward:6, melancholy:5, space:5, aura:5 }`
- 文案：你是数学摇滚。你的脑子里总在算着别人听不出的拍子。你喜欢复杂，喜欢把简单的东西拆成精巧的结构。你聪明、较真，享受那种"只有自己解得开"的乐趣。
- 金句：把简单的东西，拆成精巧。

#### 🏛️ 前卫摇滚 Progressive Rock
- 本质：宏大、复杂、知识分子的野心　·　主 order/aura/intensity　·　低 groove
- 介绍：强调复杂结构、长篇作品、技术演奏和不同音乐元素的融合。
- 向量：`{ warmth:4, intensity:8, order:9, groove:4, nostalgia:6, texture:8, inward:7, melancholy:6, space:7, aura:9 }`
- 文案：你是前卫摇滚。你受不了简单的东西，总想把一件事做到极致、做到宏大。你爱思考，也爱炫技，相信真正的作品值得几十年的耐心。你的野心不喧哗，是在结构里一层层长出来的。
- 金句：野心，在结构里一层层长出来。

#### 🌀 迷幻摇滚 Psychedelic Rock
- 本质：迷幻、飘、色彩斑斓　·　主 space/intensity/nostalgia　·　低 order/groove
- 介绍：通过效果器、重复、延展结构和特殊音色创造迷幻、梦境般的听觉体验。
- 向量：`{ warmth:5, intensity:8, order:3, groove:4, nostalgia:7, texture:5, inward:7, melancholy:7, space:8, aura:7 }`
- 文案：你是迷幻摇滚。你的世界是色彩斑斓的，意识像水一样流动。你不守规矩，喜欢让思绪飘到别人到不了的地方。你的浪漫是眩晕的、迷离的，美得不像现实。
- 金句：让思绪飘到别人到不了的地方。

#### 🎸 硬摇滚 Hard Rock
- 本质：蓝调根基、重型吉他、直接的爽　·　主 intensity/texture　·　低 inward/space
- 介绍：以强烈的吉他、鼓和人声为核心，强调厚重音色、强节奏和现场能量。
- 向量：`{ warmth:6, intensity:10, order:4, groove:7, nostalgia:6, texture:4, inward:3, melancholy:4, space:3, aura:8 }`
- 文案：你是硬摇滚。你相信力量可以直接、干脆、不绕弯。你喜欢那种一耳朵就能记住的 riff，和让全场一起沸腾的现场。你不玩深沉，也不屑装酷——爽快，就是最好的表达。
- 金句：力量不必绕弯，爽快就是表达。

#### 🤘 重金属 Heavy Metal
- 本质：极致、强力、暗黑中的秩序　·　主 intensity/aura　·　低 texture/space
- 介绍：具有强烈失真吉他、厚重鼓组和力量感，发展出大量不同子风格。
- 向量：`{ warmth:4, intensity:10, order:6, groove:7, nostalgia:3, texture:2, inward:3, melancholy:7, space:2, aura:9 }`
- 文案：你是重金属。你的力量是极致的，不给自己留退路。你看起来强硬，其实心里有自己的秩序和底线。你不是要伤害谁，只是不肯温吞地活着。
- 金句：不肯温吞地活着。

#### 📌 朋克 Punk
- 本质：反叛、简短、嘶吼　·　主 intensity/texture　·　低 order/inward
- 介绍：强调直接、快速和反叛的表达，通常结构简单、节奏强烈，具有鲜明的 DIY 文化。
- 向量：`{ warmth:5, intensity:10, order:2, groove:6, nostalgia:4, texture:1, inward:2, melancholy:3, space:2, aura:6 }`
- 文案：你是朋克。你讨厌规矩，讨厌装腔作势，讨厌一切让你觉得假的东西。你的表达简短、直接、不修饰，甚至有点冲。你不需要所有人都懂你——你只要忠于自己。
- 金句：忠于自己，其余免谈。

#### 👑 华丽摇滚 Glam Rock
- 本质：戏剧、华丽、舞台人格　·　主 aura/texture/warmth　·　低 inward
- 介绍：将摇滚音乐与夸张的服装、舞台表演和视觉形象结合，强调戏剧性和明星感。
- 向量：`{ warmth:7, intensity:7, order:6, groove:6, nostalgia:7, texture:9, inward:3, melancholy:5, space:5, aura:9 }`
- 文案：你是华丽摇滚。你相信人不可以只有一面，舞台上的那个人，也是真的你。你享受被注视，也懂得把自己活成一件作品。你的夸张不是肤浅，是认真地在演一场人生。
- 金句：把自己，活成一件作品。

### 二、流行与都市音乐（14）

#### 🎭 艺术流行 Art Pop
- 本质：前卫、戏剧、美学化的流行　·　主 texture/aura/inward　·　低 nostalgia/groove
- 介绍：将流行歌曲结构与实验性制作、视觉艺术或先锋审美结合，重视整体艺术表达。
- 向量：`{ warmth:5, intensity:7, order:6, groove:4, nostalgia:4, texture:9, inward:8, melancholy:7, space:6, aura:9 }`
- 文案：你是艺术流行。你不满足于只是"好听"，还要"独特、有态度"。你把流行当成画布，往上泼最前卫的颜色。你的美是有门槛的，懂的人会沉迷，不懂的人会困惑。
- 金句：美，只向懂的人敞开。

#### 🌫️ 梦幻流行 Dream Pop
- 本质：朦胧、梦幻、氤氲　·　主 space/melancholy/inward　·　低 groove/order
- 介绍：以柔和人声、混响、空间感和朦胧音色营造梦境般的氛围。
- 向量：`{ warmth:6, intensity:5, order:4, groove:3, nostalgia:6, texture:8, inward:9, melancholy:8, space:9, aura:5 }`
- 文案：你是梦幻流行。你像隔着一层雾看世界，柔软、模糊、不真切。你喜欢沉在情绪里，让它们慢慢发酵。你的温柔是氤氲的，不锐利，却能把人整个包住。
- 金句：隔着一层雾看世界，柔软而真切。

#### 🤖 合成器流行 Synthpop
- 本质：合成、电子、冷甜的流行　·　主 texture/groove/nostalgia　·　低 warmth/inward
- 介绍：以合成器和电子鼓为主要声音来源，在流行歌曲结构中融入明显的电子音色。
- 向量：`{ warmth:4, intensity:5, order:7, groove:8, nostalgia:8, texture:9, inward:3, melancholy:5, space:5, aura:6 }`
- 文案：你是合成器流行。你喜欢那种冷里带甜的声音，精确、干净、又有点迷人的疏离。你拥抱科技，却用它唱最柔软的心事。你的浪漫是带电流的，一闪一闪地亮。
- 金句：冷里带甜，浪漫带电流。

#### 🌃 城市流行 City Pop
- 本质：都市、怀旧、霓虹夜景　·　主 nostalgia/groove/texture　·　低 inward
- 介绍：以 70—80 年代日本都市文化为背景，融合流行、爵士、放克和迪斯科等元素，具有精致、明亮的都市感。
- 向量：`{ warmth:7, intensity:5, order:6, groove:8, nostalgia:9, texture:9, inward:4, melancholy:6, space:5, aura:6 }`
- 文案：你是城市流行。你迷恋城市的夜晚，霓虹、车流、和那种若有似无的孤独。你有一种明亮底色上的忧郁——白天笑得很好，晚上把心事留给夜色。你的怀旧，是带着光的。
- 金句：白天笑得很好，把心事留给夜色。

#### 🎶 流行摇滚 Pop Rock
- 本质：明亮、上口、有吉他但不重　·　主 groove/warmth　·　低 melancholy

## 4. 题目规格（出题哲学：让做题像在听一首歌）

**48 题、6 种"氛围题型"**。这套题不问你"喜欢什么音乐"，也不问你"遇到事情怎么做"——而是把每一题做成一小段**声音氛围切片**：文字像歌词、像专辑封面、像一段电影氛围。你读题时的感受，就是"听到一段旋律"时的感受；你的选择，是你对这段氛围最自然的反应。

**为什么这样出题**：我们要测的 10 个"声音维度"（温度/强度/秩序/律动/怀旧/质感/内省/忧郁/留白/气场），本质是"你以什么氛围存在于世上"。所以题目也必须自带氛围——让人在读题的瞬间就被带到那个情绪里，而不是在冷冰冰地做生活决策。

**出题铁律**：
1. **意象开场**：每题用光、夜、风、人群、声音、质感这类意象开头，而不是"你的朋友""你的工作"这类生活事件。
2. **选项是"反应"不是"决定"**：选项写"你此刻的感受 / 你自然的反应"，不写"你会采取的行动"。
3. **文字像歌词**：短、有画面、有情绪层次。读起来像一句歌名或一段专辑内页的话。
4. **不直白问音乐**：可以出现"音乐现场""旋律""节拍"作为氛围元素，但不问"你喜欢哪种风格 / 乐器 / 节奏"。
5. **向量规则不变**：每题 4–5 选项、单选；`vector` 只给 1–2 维、系数 +2/+3、全非负；"回避 / 翻篇 / 算了"选项标 `avoid: true`；每 5 题至少 1 处 avoid。
6. **format 只是分组标签**：下面 6 个 format 名称仅用于后端分层抽样分组，引擎不依赖名称，可按需要调整。

**6 种氛围题型**：

| format | 名字 | 氛围 | 题数 | 主打维度 |
|---|---|---|---|---|
| glow | 余晖 | 黄昏、过渡、暖调 | 8 | nostalgia / warmth / melancholy |
| night | 夜航 | 夜晚、独处、安静 | 10 | inward / space / melancholy |
| echo | 回声 | 人群、共鸣、关系 | 7 | warmth / aura / groove |
| drift | 漂浮 | 放空、流动、无时间感 | 10 | space / groove / nostalgia |
| throb | 悸动 | 渴望、强烈、心跳 | 6 | intensity / aura |
| surge | 高涨 | 迸发、投入、宣言 | 7 | intensity / groove / order |

## 5. 结算方式（计分 + 匹配公式）

`config` 与前两个内容包一致（纯余弦、无难度、无隐藏维），`dims` 换成上面的声音 10 维：

```js
config: {
  mode: 'profile',
  weights: { style: 1.0, difficulty: 0 },
  coreScale: 5, hiddenScale: 1.25, avoidThreshold: 0.5, enhanceK: 1.8,
  flatThreshold: 2.5, allRounderHigh: 7.5, allRounderMinCount: 6, allRounderFloor: 4,
  peakMin: 8.5, maxGap: 1.5, difficulty: null, extractBooks: false,
}
```

公式：

```
core[d]    = clamp( 5 + (raw[d]/avail[d]) × 5 , 0, 10 )      # 用户画像 5~10
enhance[d] = clamp( 5 + (core[d] − mean) × 1.8 , 0, 10 )      # 对比增强
final(e)   = ( 中心化余弦(enhance, 风格e) + 1 ) / 2 × 10      # 契合度
```

排序取第 1 名 =「你是X」，前 3 =「与你相近的声音」，第 2–6 =「其次」。

## 6. 结果页 & 分享设计（本项目的品牌核心）

1. **Hero 区**：emoji +「你是X。」超大居中——音乐风格天然适合配一个**专属渐变色背景**（每风格一个主色调，如 Ambient 冷灰蓝、City Pop 霓虹紫粉、Funk 橙黄），这是其他测试没有的视觉加分项。
2. **文案区**：3–4 句文学化解读，行距松、衬线字体。
3. **风格介绍**：一行客观说明"这是什么风格"，小字、灰调，放在文案下方。
4. **分享金句**：单独一行、加引号、金色高亮，可独立成分享卡。
5. **相近的声音**：`family` 前 3 张小卡，各带小 emoji + 一句式解释。
6. **雷达图折叠**：默认收起，给"查看你的完整图谱"展开按钮。
7. **（P1 预留）生成分享卡**：前端 `<canvas>` 把「渐变背景 + emoji + 你是X + 金句」合成竖版图。音乐风格是三个项目里**最适合做成分享图的**，建议优先做这个。

`details.js` 映射：`intro` = 文案正文；`works_intro` = 风格介绍（本文件"介绍"行）；`quote` = 分享金句；`source` = 风格英文名。
