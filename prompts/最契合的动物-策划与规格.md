# 最契合的动物 · 策划案 + 内容包规格（v3：生态维度 + 48 种动物）

> 定位：并列项目第二个内容包。核心钩子不是娱乐占卜式的"你是什么动物"，而是——
> **「如果你的性格是一种动物，它会是什么？」**
> 结果是具体物种 + 一段文学化的、适合截图的漂亮文案。

---

## 0. 一句话结论

动物测试**不复用文学角色的维度**，而是用一套全新的**生态维度**（群性/昼夜/领地/掠食/警觉/炫耀/蛰伏/囤积/好奇/好斗）——这些轴既是动物真正有差异的地方，又能从人的情境回答里测出来，而且本身就有梗、好传播。引擎与前端仍一行不改，只写 `entities.js`（48 只动物画像）+ `questions.js`（题目）+ `details.js`（文案）。

---

## 1. 核心钩子与差异化

| | 普通"你是什么动物" | 本项目 |
|---|---|---|
| 问题 | 你喜欢群居还是独居？(选 A 是狼) | 深夜独自在家，你更可能做什么？(间接测底层倾向) |
| 结果 | "你是狮子座——啊不，是狮子" + 一张卡通图 | "你是乌鸦。" + 一段 3–4 句文学化解读 + 一句分享金句 |
| 气质 | 星座式占卜 | 人格画像式，认真、有解释力 |

**文案模板**（每只动物固定结构，方便截图）：
```
[大号 emoji + 你是X。]
[3–4 句文学化解读：具体、第二人称、不说教]
[一句"分享金句"（可独立成分享卡）]
```

## 2. 维度（全新生态 10 维）

| key | label | adj | 高分（↗） | 低分（↘） |
|---|---|---|---|---|
| social | 群性 | 合群联结 | 合群、需要他人、为集体 | 独行、自给自足 |
| circadian | 昼夜 | 夜之生物 | 夜行、深夜最清醒 | 晨型、清晨最精神 |
| territory | 领地 | 恋家守土 | 恋家、守自己的地盘 | 四海为家、说走就走 |
| predation | 掠食 | 主动出击 | 主动争取、先下手 | 等待、伏击、随缘 |
| vigilance | 警觉 | 敏感警觉 | 对变化/威胁敏感 | 松弛、钝感、不易惊动 |
| display | 炫耀 | 张扬夺目 | 张扬、喜欢被看见 | 低调、隐没于人群 |
| dormancy | 蛰伏 | 独处回血 | 慢节奏、独处回血、需要蛰伏 | 高能量、越忙越有劲 |
| hoard | 囤积 | 未雨绸缪 | 囤、为明天准备 | 活在当下、即用即走 |
| curiosity | 好奇 | 好奇探索 | 爱尝新、爱探索 | 保守、守旧 |
| combat | 好斗 | 强势无畏 | 正面刚、无畏、强势 | 温和、避让 |

dims 数组照抄：

```js
dims: [
  { key: 'social', label: '群性', adj: '合群联结' },
  { key: 'circadian', label: '昼夜', adj: '夜之生物' },
  { key: 'territory', label: '领地', adj: '恋家守土' },
  { key: 'predation', label: '掠食', adj: '主动出击' },
  { key: 'vigilance', label: '警觉', adj: '敏感警觉' },
  { key: 'display', label: '炫耀', adj: '张扬夺目' },
  { key: 'dormancy', label: '蛰伏', adj: '独处回血' },
  { key: 'hoard', label: '囤积', adj: '未雨绸缪' },
  { key: 'curiosity', label: '好奇', adj: '好奇探索' },
  { key: 'combat', label: '好斗', adj: '强势无畏' },
],
```

> 设计要点：这 10 维两两尽量正交。`掠食`（主动争取）与 `好斗`（正面对抗）是唯一偏"攻击性"的一对，但前者测"进取方式"、后者测"冲突姿态"，靠它们能分开鲨鱼（掠食+好斗）、鳄鱼（伏击+好斗）、蜜蜂（采集+温和）这类差异。

## 3. 动物清单（48 种，含 3 种已灭绝 🦴）

每个条目：**emoji 名（具体物种）— 本质；主维；低维；向量；文案；金句**。向量直接贴进 `entities.js`。

> 区分度已设计好：每只动物的"主维"两两不撞脸，覆盖生态空间各个角落。

### A. 独行与聪明

#### 🦊 狐狸（赤狐）
- 本质：社交型聪明，点到为止的狡黠　·　主 curiosity/predation/social　·　低 display
- 向量：`{ social:7, circadian:6, territory:5, predation:6, vigilance:6, display:6, dormancy:6, hoard:5, curiosity:8, combat:5 }`
- 文案：你是狐狸。你天生懂得在人群里找缝隙，聪明，但不张扬。别人还在猜风向的时候，你已经绕着路走到了想去的地方。你的魅力在于那种点到为止的狡黠——你知道什么时候该开口，什么时候该装傻。
- 金句：聪明，但从不出头。

#### 🐈 猫（家猫）
- 本质：自我、边界、有分寸的温柔　·　主 territory/dormancy/circadian　·　低 social
- 向量：`{ social:3, circadian:7, territory:7, predation:5, vigilance:6, display:4, dormancy:7, hoard:4, curiosity:6, combat:5 }`
- 文案：你是猫。你的温柔有边界，只给愿意给的人。你不喜欢被安排，喜欢自己决定什么时候靠近、什么时候离开。别人眼里的高冷，其实是你把真心藏得很深——一旦认定了，你会用一生去陪伴。
- 金句：温柔有边界，爱得清醒。

#### 🐙 章鱼（普通章鱼）
- 本质：高智、孤独、深不可测　·　主 curiosity　·　低 social/display
- 向量：`{ social:2, circadian:6, territory:4, predation:5, vigilance:7, display:2, dormancy:7, hoard:4, curiosity:10, combat:4 }`

#### 🐦 乌鸦（小嘴乌鸦）

- 金句：站在稍远的地方，看清一切。

#### 🦎 变色龙（高冠变色龙）
- 本质：伪装、适应、慢观察者　·　主 vigilance/dormancy/curiosity　·　低 social/display/combat

- 金句：藏起来，是为了看清一切。

#### 🐍 蛇（眼镜王蛇）
- 本质：冷静、隐忍、蜕变的暗处　·　主 dormancy/combat　·　低 social/display
- 向量：`{ social:2, circadian:7, territory:6, predation:4, vigilance:6, display:3, dormancy:8, hoard:4, curiosity:4, combat:7 }`

## 4. 已灭绝生物的处理原则（重要）

1. **尊严化，不悲剧化**：渡渡鸟的"信任"、袋狼的"不被理解"、旅鸽的"归属"，都把它们当成一种**人格原型**来写，而不是拿"灭绝"当卖惨的梗。
2. **个性明确、非泛化**：三只各占一个明确的人格角落，不和其他活着的动物撞脸。
3. **数量克制**：只放 3 只，且都是大众认得出的物种。备选仅一只：🦣 猛犸象（主 dormancy/territory，时代遗民）——与大象画像过近，默认不用。

## 6. 结算方式（计分 + 匹配公式）

`config` 与文学角色**完全一致**（纯余弦、无难度、无隐藏维），只是 `dims` 换成了上面的生态 10 维：

```js
config: {
  mode: 'profile',
  weights: { style: 1.0, difficulty: 0 },
  coreScale: 5, hiddenScale: 1.25, avoidThreshold: 0.5, enhanceK: 1.8,
  flatThreshold: 2.5, allRounderHigh: 7.5, allRounderMinCount: 6, allRounderFloor: 4,
  peakMin: 8.5, maxGap: 1.5, difficulty: null, extractBooks: false,
}
```

公式：

```
core[d]    = clamp( 5 + (raw[d]/avail[d]) × 5 , 0, 10 )      # 用户画像 5~10
enhance[d] = clamp( 5 + (core[d] − mean) × 1.8 , 0, 10 )      # 对比增强
final(e)   = ( 中心化余弦(enhance, 动物e) + 1 ) / 2 × 10      # 契合度
```

排序取第 1 名 =「你是X」，前 3 =「与你相近的动物」，第 2–6 =「其次」。

2. **文案区**：`intro`（3–4 句文学化解读）行距松、衬线字体。
3. **分享金句**：`quote` 单独一行、加引号、金色高亮，可独立成分享卡。
4. **相近的动物**：`family` 前 3 张小卡，各带小 emoji + 一句式解释，弱化处理。
5. **雷达图折叠**：默认收起，给"查看你的完整图谱"展开按钮。
6. **（P1 预留）生成分享卡**：前端 `<canvas>` 把「emoji + 你是X + 金句」合成竖版 PNG，比手动截图更可控。这是动物测试唯一需要的新前端能力。

`details.js` 映射：`intro` = 文案正文；`quote` = 分享金句；`source` = 具体物种名；`works` 可留空或填拉丁学名。
