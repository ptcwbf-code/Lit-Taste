# 最契合的美学流派 · 策划案 + 内容包规格（v2 · 48 流派）

> 定位：并列项目第六个内容包。核心钩子——
> **「你是哪一种美学？」**
> 不是"你喜欢什么风格"（口味），而是"你以什么审美姿态活着"——你的房间、你偏爱的光、你愿意戴上的那张脸。结果是具体美学流派 + 一段文学化解读 + 一张"美学名片"分享图。

---

## 0. 一句话结论

复用平台引擎（纯余弦匹配），只写 `tests/aesthetic/` 内容包。核心差异：

1. **维度**：全新"美学 10 维"——测"你被什么美打动、你以什么姿态装点世界"，既能从当下的审美直觉测出，又能标到每个美学流派上。
2. **视觉（本项目命门）**：美学流派是六个包里**最依赖视觉**的——每个流派配专属渐变色 + 视觉符号 + "美学名片"分享卡。这是它天然适合传播（小红书/TikTok 式审美人格测试）的原因。

---

## 1. 核心钩子与差异化

| | 普通"审美测试" | 本项目 |
|---|---|---|
| 问法 | 你喜欢甜系还是暗黑系？（直白分类） | 你会把房间布置成什么样 / 你被哪束光打动（间接测审美直觉） |
| 结果 | "你是甜美系" + 一句标签 | "你是 Coquette。" + 文学化解读 + 一张可分享的美学名片 |
| 气质 | 分类占卜 | 审美人格的归属感，认真、有解释力、极度可截图 |

**关键区分（务必守住）**：题目绝不同"你喜欢哪种风格 / 你的穿搭是哪种"，只测**此刻的审美直觉**——你对光与暗、繁与简、旧与新的本能倾向。美学流派是结果，不是提问素材。

**文案模板**（每个流派固定结构）：

```
[视觉符号 emoji + 你是X。]
[3–4 句文学化解读：把你此刻的审美，翻译成那种美学的光]
[一句"美学金句"（可独立成名片落款）]
```

## 2. 维度（全新"美学"10 维）

每一维都是"一种美的方式"，也是"你当下的审美本能"。高分 = 靠近该维"上端"。

| key | label | 高分（↗ 你是这样的美） | 低分（↘ 你是这样的美） |
|---|---|---|---|
| luminance | 明度 | 发光、明亮、清澈、糖果色 | 幽暗、深邃、阴翳 |
| dulcet | 甜度 | 甜美、治愈、柔软 | 酸涩、锋利、带刺 |
| ornate | 繁饰 | 繁复、华丽、堆叠 | 极简、留白、空旷 |
| retro | 怀旧 | 旧时光、档案、回忆 | 未来、前卫、崭新 |
| organic | 原生 | 天然、手作、粗粝 | 人工、合成、精致 |
| unruly | 乖张 | 反叛、越界、不驯 | 守序、乖巧、合群 |
| numinous | 灵光 | 神圣、崇高、纯净 | 世俗、功利、现实 |
| childlike | 童真 | 童稚、可爱、天真 | 成熟、世故、苍老 |
| theatrical | 戏剧 | 浓烈、夸张、表演性 | 内敛、真实、低调 |
| ethereal | 缥缈 | 梦幻、超现实、轻盈 | 实在、厚重、接地 |

dims 数组照抄：

```js
dims: [
  { key: 'luminance', label: '明度', adj: '发光清澈' },
  { key: 'dulcet', label: '甜度', adj: '甜美治愈' },
  { key: 'ornate', label: '繁饰', adj: '繁复华丽' },
  { key: 'retro', label: '怀旧', adj: '旧时档案' },
  { key: 'organic', label: '原生', adj: '天然手作' },
  { key: 'unruly', label: '乖张', adj: '反叛越界' },
  { key: 'numinous', label: '灵光', adj: '神圣纯净' },
  { key: 'childlike', label: '童真', adj: '童稚天真' },
  { key: 'theatrical', label: '戏剧', adj: '浓烈夸张' },
  { key: 'ethereal', label: '缥缈', adj: '梦幻轻盈' },
],
```

> 设计说明：这 10 维与音乐（声音）、时代（精神）刻意不重复——全走**视觉/感官/姿态**路线。易混三对：`甜度`（甜 vs 刺）与 `童真`（幼稚 vs 世故）一个测味道一个测心智；`繁饰`（华丽 vs 极简）与 `戏剧`（浓烈 vs 内敛）一个测装饰度一个测表现欲；`灵光`（神圣 vs 世俗）与 `缥缈`（梦幻 vs 实在）一个测超验一个测轻盈。

## 3. 流派清单（48 个 · 6 板块 · 气质两两不撞）

每个条目：**意象 emoji + 中文名 + 英文名 — 本质一句话；主维/低维；向量；文案；金句**。向量直接贴进 `entities.js`（10 维、0–10 整数，主维 8–10、低维 2–4、其余 5–7）。生成后跑两两余弦，目标无 >0.85 对。

### A. 光与甜（甜美明亮系，8）

#### 🎀 Coquette 娇媚少女
- 本质：蝴蝶结、缎带、柔美的轻佻　·　主 dulcet / luminance / theatrical　·　低 organic / numinous
- 向量：`{ luminance:8, dulcet:9, ornate:7, retro:5, organic:4, unruly:5, numinous:4, childlike:6, theatrical:7, ethereal:6 }`
- 文案：你是娇媚少女。你把日子系上一只蝴蝶结，连认真都带一点轻盈的挑逗。你懂得美是一种姿态，不必用力，一个眼神就够了。你的柔，是有锋芒的柔。
- 金句：美，是一种不必用力的姿态。

#### 🍬 Sweet Lolita 甜系洛丽塔

- 金句：对美好的固执，也是一种勇敢。

#### 🧸 Kawaii 卡哇伊

- 金句：可爱，是我对抗坚硬的方式。

#### 🍓 Strawberry Girl 草莓女孩

- 金句：把日子过成一口甜。

#### ☁️ Softie 软妹系
- 本质：云朵、奶油、被温柔包裹　·　主 dulcet / luminance / childlike　·　低 unruly / organic

- 金句：温柔，是我的超能力。

#### 👑 Princesscore 公主核
- 本质：缎带、城堡、被珍视的梦　·　主 ornate / dulcet / numinous　·　低 unruly / organic

- 金句：值得被珍视，是每个人的权利。

#### 💗 Barbiecore 芭比核

- 金句：亮，从来不是罪。

#### 🌸 Girly Girl 少女系

- 金句：把日子过成粉色。

- 金句：知识的幽暗，也是一种光。

## 4. 题目规格（延续氛围切片，但换成"审美直觉"）

**48 题、6 种"美学氛围题型"**。题目绝不同"你喜欢哪种风格 / 你的穿搭"，只测**此刻的审美直觉**：你对光与暗、繁与简、旧与新、甜与刺的本能倾向。流派是结果，不是提问素材。

| format | 名字 | 氛围 | 题数 | 主打维度 |
|---|---|---|---|---|
| tint | 色调 | 光影、颜色、一天中的光 | 8 | luminance / dulcet / numinous |
| nest | 巢居 | 房间、陈设、居住的角落 | 10 | ornate / organic / childlike |
| keepsake | 旧物 | 旧物、记忆、传家的东西 | 8 | retro / numinous / dulcet |
| garb | 衣装 | 外表、姿态、愿意戴的脸 | 8 | theatrical / unruly / childlike |
| vista | 景致 | 风景、想去的地方 | 8 | ethereal / organic / luminance |
| glyph | 印记 | 符号、图腾、信仰 | 6 | numinous / unruly / ornate |

```js

```

公式（同前）：

```
core[d]    = clamp( 5 + (raw[d]/avail[d]) × 5 , 0, 10 )
enhance[d] = clamp( 5 + (core[d] − mean) × 1.8 , 0, 10 )
final(e)   = ( 中心化余弦(enhance, 流派e) + 1 ) / 2 × 10
```

排序取第 1 名 =「你是X」，前 3 =「与你相近的美学」，第 2–6 =「其次」。

## 6. 结果页 & 分享设计（本项目传播命门）

美学流派是六个包里**最适合做视觉**的：

1. **Hero 区**：每个流派一个**专属渐变色 + 大号视觉符号**（🎀 / 🖤 / 🌿 / 🌴 / 🌃 / 🃏…），配「你是 X」超大标题。背景用该流派的"主色渐变"（如 Coquette=粉白、Goth=黑紫、Naturecore=苔绿、Vaporwave=粉蓝）。
2. **美学文学解读**：3–4 句第二人称——"你是俏皮少女。你把日子系上一只蝴蝶结……"。
3. **美学金句**：独立一行、引号、金色高亮，可作为名片落款。
4. **相近的美学**：`family` 前 3，小卡带视觉符号 + 一句 why。
5. **雷达图折叠**：`foldRadar: true`，默认收起（视觉优先）。
6. **分享卡 = 美学名片**（P0，重点做）：canvas 竖版，背景用该流派的**专属渐变 + 纹理**，顶部大视觉符号 + 流派名，中部金句，底部二维码。参考历史时代的 `postcardCard`（含 seal 印章逻辑），美学版把"印章"换成"流派符号角标"。
7. **目录页小卡**：用流派专属渐变色块打底 + 符号，不用统一灰卡——这是六个包第一个让目录也"有色"的。

`details.js` 映射：`intro` = 文学解读；`works_intro` = 一两句客观说明（如"源自 2010 年代互联网美学，以蝴蝶结、缎带、柔美风情为标志"）；`quote` = 美学金句；`source` = 流派英文名；`gradient` = 专属渐变色；`seal` = 视觉符号文字（可选，用于名片角标）。
